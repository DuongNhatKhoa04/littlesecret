Lưu ticket ra file (ticket system không vào được)

    

      

      

      

      
      
Tải 1 file, tên bắt đầu bằng mã OFF-…: không có ảnh là file .json; có ảnh là file .zip chứa .json + ảnh (+ .pdf nếu chọn) cùng tên. Mở lại bằng Khác → Mở file đã lưu.

    

    

      
      
      
    

  




  

    Nhận ảnh iOS
    
  

  

    
iPad / iPhone (cùng Wi-Fi với máy này): mở Camera, hướng vào mã → bấm link hiện ra → Chọn ảnh để gửi. Ảnh tự vào mục đang mở, như Ctrl+V.

    
    

    

  

  

    
    
    
  




  

    Bookmark: Điền ticket · Lấy thông tin tiệm
    
  

  

    
Cài 1 lần

    
    
      
  1. Bật thanh bookmark: Ctrl+Shift+B.
    2. 
      
  2. Kéo nút này thả lên thanh bookmark (đừng bấm): Điền ticket
    3. 
    

    
Mỗi lần tạo ticket

    
    
      
  1. Ở Ticket Writer bấm Copy để điền.
    2. 
      
  2. Chuyển sang tab ticket, bấm bookmark Điền ticket: Title vào Subject, Nội dung vào Description, done vào ô Comment ở khung Checklist, rồi tự bấm Upload File(s). Lần đầu Chrome hỏi quyền xem clipboard → Allow.
    3. 
      
  3. Trang không có ô Comment (ticket không có khung Checklist) thì bỏ qua ô này. Thiếu Subject / Description / nút Upload thì không điền gì và báo thiếu cái nào.
    4. 
    

    
Bản Ticket Writer mới có sửa phần điền ticket thì kéo lại nút ở trên (xóa bookmark cũ).

    
Lấy thông tin tiệm (Chuyển case)

    
    
      
  1. Kéo nút này thả lên thanh bookmark (đừng bấm): Lấy thông tin tiệm
    2. 
      
  2. Trên portal, bấm bookmark Lấy thông tin tiệm và nó báo lấy được gì:
        
      
          
    • Trang ticket: Link Ticket + Tên tiệm + MID (dòng Ticket #… for Tên tiệm / MID) + nội dung ticket (vào ô Issue).
      • 
          
    • Trang Lead: Link Lead + DBA + MID + Business ZIP.
      • 
        
    
      
    3. 
      
  3. Về Ticket Writer → Chuyển case → bấm Dán thông tin tiệm: điền các trường lấy được (ghi đè chữ cũ). Không muốn Chrome hỏi quyền xem clipboard: bấm Ctrl+V ở bất kỳ đâu trên trang Chuyển case thay cho nút (dán bằng phím thì Chrome không hỏi).
    4.
