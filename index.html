Lưu offline (ticket system không vào được)

    

      

      

      
      
Tải 1 file, tên bắt đầu bằng mã OFF-…: không có ảnh là file .json; có ảnh là file .zip chứa .json + ảnh (+ .pdf nếu chọn) cùng tên. Mở lại bằng "Mở file offline".

    

    

      
      
      
    

  




  

    Điền ticket: Subject, Description, Comment (Checklist) rồi bấm Upload File(s)
    
  

  

    
Cài 1 lần

    
    
      
  1. Bật thanh bookmark: Ctrl+Shift+B.
    2. 
      
  2. Kéo nút này thả lên thanh bookmark (đừng bấm): Điền ticket
    3. 
    

    
Mỗi lần tạo ticket

    
    
      
  1. Ở Ticket Writer bấm Copy để điền.
    2. 
      
  2. Chuyển sang tab ticket, bấm bookmark Điền ticket: Title vào Subject, Nội dung vào Description, done vào ô Comment ở khung Checklist, rồi tự bấm Upload File(s). Lần đầu Chrome hỏi quyền xem clipboard → Allow.
    3. 
      
  3. Trang không có ô Comment (ticket không có khung Checklist) thì bỏ qua ô này. Thiếu Subject / Description / nút Upload thì không điền gì và báo thiếu cái nào.
    4. 
    

    
Bản Ticket Writer mới có sửa phần điền ticket thì kéo lại nút ở trên (xóa bookmark cũ).
