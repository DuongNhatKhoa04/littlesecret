Cây thư mục Ticket Writer

1 · Tổng quan

2 · src/ (Clean Architecture)

3 · config/ (thêm loại / checklist ở đây)

Số file đếm lúc sinh sơ đồ. Thêm loại ticket hoặc checklist = thêm file trong config/, không sửa src/. Checklist setup theo đường config/setup/<thiết bị>/<hãng>/<new|replace>/<checklist>.js. Ở gốc còn README.md, CLAUDE.md, CHANGELOG.md, skills-lock.json.
